# 🍹 Drinks Fest

## 📌 Sobre o projeto

A **Drinks Fest** é uma Landing Page criada para divulgar um serviço de bartender para festas, comemorações e eventos.

O projeto foi desenvolvido como parte do **Desafio 01**, com o objetivo de transformar uma ideia de negócio em uma página web real, responsiva, acessível e publicada na internet.

## 🎯 Objetivo

A Landing Page apresenta os principais serviços da Drinks Fest, informações sobre a marca, tipos de eventos, galeria de drinks e canais de contato para solicitação de orçamento.

### Serviços apresentados

* 🍹 Bartender para eventos
* 🍸 Open Bar
* 🥂 Drinks personalizados

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Git
* GitHub
* GitHub Pages
* Inteligência Artificial como ferramenta de apoio

## 📱 Responsividade

A página foi desenvolvida para funcionar em diferentes dispositivos:

* 📱 Celular
* 📲 Tablet
* 💻 Desktop

O CSS utiliza recursos de responsividade para adaptar o conteúdo aos diferentes tamanhos de tela.

## ♿ Acessibilidade

O projeto utiliza HTML semântico, incluindo:

* `header`
* `nav`
* `main`
* `section`
* `article`
* `footer`

As imagens possuem o atributo `alt` com descrições relacionadas ao conteúdo visual.

Também foi utilizada uma hierarquia adequada de títulos para facilitar a navegação e compreensão da página.

## 🚫 Regras do desafio

O projeto foi desenvolvido seguindo as regras propostas no desafio.

* ❌ Não foi utilizado JavaScript.
* ❌ Não foi utilizado CSS inline.
* ❌ Não foram utilizadas tags `<style>` dentro do HTML.

* ✅ Foi utilizado HTML5 semântico.
* ✅ O projeto foi publicado através do GitHub Pages.
